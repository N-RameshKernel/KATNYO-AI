Provider session

Connect an AI provider for profile-based dataset chat in the AutoML console.

The key is sent only to the KATNYO backend for this session.

Keys stay in backend process memory for up to 12 hours, are not written to disk, and are never returned to this page. Clearing a provider or ending the session removes them. Restarting the API clears all session keys. Dataset chat sends profile metadata, not raw CSV rows.
